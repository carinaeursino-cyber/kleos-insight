## 📞 PREGUNTAS FRECUENTES

**P: ¿Por qué hay 4 docs? ¿No puede ser 1?**
R: Cada doc tiene audience diferente. PM necesita entender POR QUÉ. Dev necesita código exacto. Designer necesita visual. Cada doc es optimizado para su audiencia.

**P: ¿En qué orden leo si no entiendo de PM?**
R: 1) DEVELOPER_QUICKSTART (código) → 2) MVP_V1_PRD (context) → 3) MVP_V1_SIMPLIFIED_DESIGN (visual)

**P: ¿Qué si no entiendo algo?**
R: 
- HTML → Busca en DEVELOPER_QUICKSTART
- Requirements → Busca en MVP_V1_PRD
- Diseño visual → Busca en MVP_V1_SIMPLIFIED_DESIGN
- Estrategia → Busca en EXECUTIVE_SUMMARY

**P: ¿Puedo empezar sin leer todo?**
R: SÍ, si eres dev: lee DEVELOPER_QUICKSTART + MVP_V1_PRD sección 4. Eso es suficiente.

**P: ¿Y si hay conflicto entre docs?**
R: No hay conflicto. Son complementarios:
- PRD = requirements
- Design = visual
- Dev = código (código siempre es fuente de verdad)
